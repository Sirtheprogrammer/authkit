Architecture & Capabilities

Built for Portability, Speed & Simplicity

100% Stateless & JWKS Ready

Microservices and frontend apps verify tokens instantly with standard RFC 7517 public keys (/.well-known/jwks.json). Zero database queries required on downstream API requests.

Multi-Database Freedom

Switch between SQLite (zero-config local default), PostgreSQL, MySQL, and MongoDB with a single environment variable. Auto-migrations run on boot.

Dynamic Custom Schema

Store and validate arbitrary custom fields (phone, company, roles, address, tier) with strict or flexible schema validation. Zero manual SQL migrations needed.

Google, Firebase & GitHub OAuth

One-click Google Cloud OAuth, GitHub OAuth, and direct Firebase ID token verification. Seamlessly links external identities to AuthKit user profiles.

Bring-Your-Own Email & Resend

Configure custom SMTP credentials or use the Resend SDK. Comes out-of-the-box with beautiful monochromatic responsive HTML email templates for OTP verification and password reset.

Model Context Protocol (MCP) AI

Equipped with an MCP server (JSON-RPC 2.0 over Stdio and HTTP). Empower Claude Desktop, Cursor, and autonomous AI agents to manage users, tokens, and auth logs.

Integration

Verify Tokens in Any Language

Because AuthKit emits standard RFC 7517 JWKS tokens, downstream services can verify signatures locally in microseconds with zero network or database latency. 

# 1. Signup with dynamic metadata
curl -X POST http://localhost:8080/api/v1/auth/signup \
  -H "Content-Type: application/json" \
  -d '{
    "email": "user@example.com",
    "password": "Password123!",
    "metadata": { "name": "Jane Doe", "tier": "pro" }
  }'

# 2. Get Public Key Set (JWKS) for stateless token verification
curl http://localhost:8080/.well-known/jwks.json
import { createRemoteJWKSet, jwtVerify } from 'jose';

// Downstream Next.js / Express middleware verifies tokens statelessly!
const JWKS = createRemoteJWKSet(new URL('http://localhost:8080/.well-known/jwks.json'));

export async function verifyAuthKitToken(token: string) {
  const { payload } = await jwtVerify(token, JWKS, {
    issuer: 'authkit',
  });

  return {
    userId: payload.sub,
    email: payload.email,
    role: payload.role,
    metadata: payload.metadata, // Custom schema attributes
  };
}
import jwt
from jwt import PyJWKClient

# Python FastAPI stateless verification
jwks_client = PyJWKClient("http://localhost:8080/.well-known/jwks.json")

def verify_token(token: str):
    signing_key = jwks_client.get_signing_key_from_jwt(token)
    data = jwt.decode(
        token,
        signing_key.key,
        algorithms=["RS256"],
        audience="authkit-api",
        issuer="authkit"
    )
    return data  # Contains sub, email, role, and custom metadata
